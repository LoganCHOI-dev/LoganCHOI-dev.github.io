Roulette 개인정보처리방침

Roulette(한국어 가제: 룰렛 돌리기, 이하 “앱”)는 사용자가 항목과 비율을 설정하고 룰렛을 돌려 결과를 확인할 수 있는 Android 앱입니다. 본 방침은 앱이 처리하는 정보, 저장 위치와 사용자의 선택권을 설명합니다.

앱은 자체 회원가입, 개발자 운영 서버 저장 또는 계정 동기화 기능을 제공하지 않습니다. 사용자가 입력한 항목과 비율은 기본적으로 기기 내부에 저장됩니다.

1. 앱이 처리하는 정보

앱은 룰렛 기능과 설정 유지를 위해 다음 정보를 기기 내부에서 처리합니다.

  • 사용자가 입력한 룰렛 항목 이름, 포함 여부와 가중치
  • 표시 항목 수와 마지막 룰렛 구성
  • 언어, 소리, 진동과 광고 표시 간격 관련 설정
  • 앱 종료 또는 화면 재생성 뒤 동일 결과를 복원하기 위한 진행 상태

앱은 항목 이름이나 가중치 원문을 개발자 서버 또는 Firebase 맞춤 분석 이벤트로 전송하지 않습니다. 현재 Firebase 맞춤 분석 이벤트는 연결되어 있지 않습니다.

2. 광고와 동의 관리

앱은 하단 배너 광고와 자연스러운 결과 구간의 전면 광고를 제공하기 위해 Google Mobile Ads SDK를 사용하고, 지역에 따라 광고 개인정보 선택사항을 제공하기 위해 Google User Messaging Platform을 사용합니다.

Google Mobile Ads SDK는 광고 제공, 분석, 진단과 부정행위 방지를 위해 IP 주소(대략적인 위치 추정에 사용될 수 있음), 앱 상호작용, 진단 정보, 광고 ID·앱 세트 ID 등 기기 또는 계정 식별자를 자동으로 수집하거나 Google과 공유할 수 있습니다. 이 데이터는 전송 중 암호화되며 Google 정책에 따라 처리됩니다.

3. 권한 사용

  • 인터넷 및 네트워크 상태: 광고와 개인정보 선택사항을 요청하기 위해 사용합니다.
  • 진동: 사용자가 진동 설정을 켠 경우 룰렛 경계와 결과 피드백을 제공하기 위해 사용합니다.
  • 광고 ID 및 Ad Services 관련 권한: Google Mobile Ads SDK의 광고, 측정과 부정행위 방지 기능을 위해 SDK가 병합합니다.

앱은 카메라, 사진, 위치 센서, 연락처, 캘린더, 건강 또는 금융 정보 권한을 요청하지 않습니다.

4. 저장 위치와 보관 기간

룰렛 항목과 설정은 사용자가 수정·초기화하거나 앱 데이터를 삭제할 때까지 Android 앱 전용 저장소에 보관됩니다. 기기 및 Android 백업 설정에 따라 앱 데이터가 시스템 백업에 포함될 수 있으며, 이는 개발자가 운영하는 서버 저장 기능이 아닙니다.

5. 삭제와 사용자 선택

  • 항목과 비율은 앱 안에서 수정하거나 전체 초기화할 수 있습니다.
  • 기기 설정에서 앱 데이터를 삭제하거나 앱을 제거하면 기기 내부 데이터가 삭제됩니다.
  • 광고 ID는 Android 설정에서 재설정하거나 삭제할 수 있습니다.
  • 해당 지역에서 필요한 경우 앱 메뉴의 개인정보 선택사항에서 광고 동의 선택을 변경할 수 있습니다.

6. 제3자 제공

개발자는 사용자가 입력한 룰렛 항목이나 비율을 자체 서버에 업로드하거나 판매하지 않습니다. 다만 광고와 동의 관리 과정에서 위에 설명한 광고 관련 데이터가 Google에 전송될 수 있습니다. 사용자가 “앱 공유하기”를 선택하면 Android 공유 화면을 통해 Play 스토어 링크를 사용자가 선택한 외부 앱으로 보냅니다.

7. 아동의 개인정보

앱은 아동을 주요 대상으로 설계되지 않았으며 아동의 개인정보를 고의로 수집하기 위한 계정, 메시지 또는 콘텐츠 업로드 기능을 제공하지 않습니다. 최종 배포 대상 연령은 Play Console에서 별도로 확정합니다.

8. 보안

앱의 룰렛 데이터는 Android 앱 전용 저장소에 보관됩니다. 제3자 SDK가 네트워크로 데이터를 전송하는 경우 해당 SDK의 보안 정책을 따릅니다. 사용자는 기기 잠금과 최신 운영체제 유지로 기기 내 데이터를 보호할 수 있습니다.

9. 방침 변경

앱 기능, 사용 SDK, 법령 또는 정책이 바뀌면 이 방침을 수정할 수 있습니다. 중요한 변경은 이 페이지를 통해 알립니다.
